# Max Player

Плеер для музыки с телефона: выбор папки, очередь, перемешивание и повтор, трёхполосный эквалайзер. Воспроизведение продолжается при выключенном экране, управление есть в шторке уведомлений.

## Как получить APK

APK собирает GitHub, ничего ставить на компьютер не нужно.

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта ещё нет.
2. Создайте репозиторий: **+ → New repository**, имя любое (например, `max-player`), остальное по умолчанию. Нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file** и перетащите в окно **всё содержимое** распакованной папки `max-player-android`, включая папки `app`, `gradle` и `.github`. Нажмите **Commit changes**.
4. Если папка `.github` не загрузилась (браузер иногда не берёт папки с точкой в имени), создайте файл вручную: **Add file → Create new file**, в имя вставьте `.github/workflows/build.yml`, в тело вставьте содержимое файла `.github/workflows/build.yml` из архива и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка запустится сама и займёт 5–8 минут. Если не запустилась, выберите **Build APK → Run workflow**.
6. Когда у сборки появится зелёная галочка, откройте справа на главной странице репозитория раздел **Releases → Max Player (последняя сборка)** и скачайте `MaxPlayer.apk`. Запасной вариант: на странице сборки, внизу, в блоке **Artifacts**, лежит архив `MaxPlayer-apk`.

## Установка на телефон

1. Откройте скачанный `MaxPlayer.apk`. Телефон попросит разрешить установку из этого источника (браузера или «Файлов»), разрешите.
2. Нажмите **Установить**. Если Play Protect предупредит о неизвестном разработчике, выберите **Всё равно установить**: приложение подписано личным ключом, а не ключом Google Play.
3. При первом запуске разрешите уведомления: в них будут кнопки «Назад», «Пауза», «Вперёд».
4. Нажмите **Папка** и выберите каталог с музыкой. Плеер запомнит его и откроет сам при следующем запуске.

Новые версии можно ставить поверх старых: ключ подписи у всех сборок один и тот же.

## Что внутри

- `app/src/main/assets/index.html`: сам плеер (интерфейс, эквалайзер, очередь).
- `MainActivity.java`: окно приложения, выбор папки через системный диалог Android, отдача файлов странице с перемоткой.
- `PlaybackService.java`: служба для фонового воспроизведения и уведомления с кнопками.
- `app/debug.keystore`: ключ подписи (пароль `android`). Подходит для личного использования. Для публикации в Google Play нужен свой ключ.

## Если сборка не прошла

Откройте красную сборку во вкладке **Actions**, нажмите на шаг **Build** и скопируйте последние строки с ошибкой.
